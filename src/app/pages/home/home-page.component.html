Propiedades
Uso de propiedades del component.ts

Las propiedades del componente se encuentran en el archivo component.ts y se pueden acceder a ellas en el HTML con el uso de las llaves dobles.
{{ '{{ propertyName }}' }}

En Angular, las propiedades son declaradas como señales para que apunten a un valor especifico public property = singal( value )

Rutas
Manejo de rutas en la aplicacion

Las rutas de la aplicacion de definen en el archivo app.routes.ts y es una clase que tiene un arreglo de objetos con las propiedades path y component

La propiedad path representa la ruta al componente que se quiere visualizar mientras que la porpiedad component renderiz el componente para visualizarlo.
Si no se importa el componente no se mostrara

{{ 'routes=[{ path: /somePage, component: SomeComponent }]' }}
Eventos
Uso de evoentos en las etiquetas HTML

Los eventos en Angular sirven para dar accion a un elemento html a traves de una funcion definida en el component.ts
Son comunmente usados en botones y se declaran con un (event) = "functionName()" en la etiquita HTML que va a realizar la accion.

(click) = "functionName"
Metodos
Uso de metodos

Los metodos son funciones que se pueden inocar en elementos HTML para que realicen una accion en especifico.

Document Object Model (DOM)
Actualizacion de valores en el DOM

El uso de las propiedades como SEÑALES en Angular permite mostrar y cambiar el valor de una propiedad especifica

Para mostrar el valor de una señal solo basta con invocar la propiedad den las llaves.
Las señales son funciones por lo tanto se invocan como una funcion sin argumentos.

Para actualizar el valor de una señal o propiedad, se utilizan 2 metodos.

  • .set(newValue) - Este se usa para establecer un valor e igno caulquier otro que ya tenga
  • .update( function ) - si una señal depende del estado en el que se encuentre, se usa el update
